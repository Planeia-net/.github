# Planeia-net organization agent router

For writing tasks, load only the canonical standards that apply:

- Publishable prose -> `writing/human-writing.md`
- Insurance content -> `writing/insurance-boundaries.md`
- SEO / organic search -> `writing/seo-writing.md`
- Research, factual claims, statistics, legal/regulatory or current information -> `writing/source-policy.md`

Repository-specific instructions may add stricter brand, channel, product, or workflow rules. They must not weaken factual accuracy, compliance, or source discipline.

Do not duplicate canonical standards locally.


## Image and video generation

When a user asks to generate or edit images or video involving realistic people or avatars, reference-derived camera angles, relighting, or continuity-aware motion, load https://github.com/Planeia-net/.github/blob/main/.agents/skills/image-video-generation/SKILL.md and follow it. Load only for relevant visual-generation tasks; it does not require a photorealistic style when the brief calls for another medium.

## Google Ads images

When a user asks to "create google ads images", create Google Ads image ads, Performance Max/PMax images, or an equivalent request in another language, load https://github.com/Planeia-net/.github/blob/main/.agents/skills/google-ads-images/SKILL.md and follow it. Read the current https://github.com/Planeia-net/.github/blob/main/google-ads-images for size instructions before generation. Load these files only for relevant image tasks.
