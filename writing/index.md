# Organization Writing Standards

Canonical writing standards for repositories in the Planeia-net organization.

Load only what the task needs:

- Publishable prose -> [human-writing.md](./human-writing.md)
- Insurance content -> [insurance-boundaries.md](./insurance-boundaries.md)
- SEO / organic-search work -> [seo-writing.md](./seo-writing.md)
- Research, factual claims, statistics, legal/regulatory or current information -> [source-policy.md](./source-policy.md)

Repository-specific instructions may add brand, channel, product, design, or workflow rules. They must not weaken factual accuracy, compliance, or source-discipline requirements.

Do not duplicate these standards into project-specific files. Link to the canonical file instead.
