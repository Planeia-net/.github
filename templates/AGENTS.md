# Repository agent router

For writing tasks, load only the organization standards that apply:

- Publishable prose: https://github.com/Planeia-net/.github/blob/main/writing/human-writing.md
- Insurance content: https://github.com/Planeia-net/.github/blob/main/writing/insurance-boundaries.md
- SEO / organic search: https://github.com/Planeia-net/.github/blob/main/writing/seo-writing.md
- Research, factual claims, statistics, legal/regulatory or current information: https://github.com/Planeia-net/.github/blob/main/writing/source-policy.md

Do not load unrelated standards. Repository-specific rules may add stricter brand, channel, product, design, or workflow requirements but must not weaken factual accuracy, compliance, or source discipline.
